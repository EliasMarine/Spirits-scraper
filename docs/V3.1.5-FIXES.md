# V3.1.5 SPIRITS DATABASE ISSUES & FIXES

## Audit Date: June 30, 2025

## CRITICAL ISSUES IDENTIFIED

### 1. DUPLICATE ENTRIES (CRITICAL)
- **Pattern**: Same spirit scraped multiple times with slight variations
- **Examples**:
  - "Buffalo Trace Bourbon" appears twice with different brands ("Buffalo" vs "Buffalo Trace")
  - "Blanton's Straight" duplicated with brands "Blanton's" vs "Blanton'S Straight From"
  - "Angel's Envy Bourbons Kentucky Bourbons Angel's Envy" duplicated
- **Impact**: 15-20% of recent entries are duplicates
- **Root Cause**: Poor brand normalization and lack of duplicate detection

### 2. DATA QUALITY ISSUES

#### A. Very Low Quality Entries (data_quality_score < 30)
- **"Scotch Whisky"** - Generic name, brand "Unknown", score: 10
- **"Scotch Brite Dobie 2.6 In. X 4.3 In. X 0.5 In. All Purpose Cleaning"** - Not even a spirit! It's a cleaning product
- **"Latest Outturn The Latest Whisky Releases"** - Blog title, not a product
- **"Substitute For Goslings Black Seal Rum Badger & Blade"** - Forum discussion title

#### B. Poor Descriptions
- Many entries with "Find the best local for..." - scraping search result snippets
- Descriptions containing navigation text, related products, pricing info
- Truncated descriptions with ellipsis

#### C. Brand Name Issues
- Inconsistent capitalization: "Angel's Envy" vs "Angel'S Envy"
- Truncated brands: "Widow" instead of "Widow Jane"
- Generic brands: "The", "Eight New", "Bottled"

### 3. MISSING CRITICAL DATA
- **Price**: Only 26.3% have prices (1088/4139)
- **ABV**: 66.2% have ABV (2738/4139)
- **Description**: 29% have no meaningful description

### 4. CATEGORY MISCLASSIFICATION
- Scotch cleaning products classified as "Scotch" whisky
- Blog posts and articles scraped as products
- Forum discussions treated as spirits

### 5. NAME FORMATTING ISSUES
- **Concatenated text**: "Four Roses'private Selection'single" (missing spaces)
- **Mixed capitalization**: "Widow Jane'baby Jane'heirloom"
- **Excessive length**: Names including full descriptions

## DATA CLEANUP QUERIES

### 1. Remove Obvious Duplicates
```sql
-- Delete duplicates keeping the highest quality score
WITH duplicates AS (
    SELECT id, name, data_quality_score,
           ROW_NUMBER() OVER (PARTITION BY LOWER(name) ORDER BY data_quality_score DESC, created_at DESC) as rn
    FROM spirits
)
DELETE FROM spirits
WHERE id IN (
    SELECT id FROM duplicates WHERE rn > 1
);
```

### 2. Fix Brand Names
```sql
-- Normalize brand capitalization
UPDATE spirits 
SET brand = INITCAP(brand)
WHERE brand != INITCAP(brand);

-- Fix common brand issues
UPDATE spirits SET brand = 'Angel''s Envy' WHERE LOWER(brand) LIKE '%angel%envy%';
UPDATE spirits SET brand = 'Four Roses' WHERE LOWER(brand) LIKE '%four%roses%';
UPDATE spirits SET brand = 'Widow Jane' WHERE brand = 'Widow' AND name LIKE 'Widow Jane%';
```

### 3. Remove Bad Entries
```sql
-- Delete entries with cleaning products, blog posts, etc
DELETE FROM spirits
WHERE 
    -- Cleaning products
    LOWER(name) LIKE '%scotch%brite%' OR
    LOWER(name) LIKE '%cleaning%' OR
    -- Blog titles
    LOWER(name) LIKE '%best%price%' OR
    LOWER(name) LIKE '%essential%bottles%' OR
    LOWER(name) LIKE '%latest%releases%' OR
    -- Forum posts
    LOWER(name) LIKE '%substitute%for%' OR
    LOWER(name) LIKE '%vs%' OR
    -- Recipes
    LOWER(name) LIKE '%mojito%' OR
    LOWER(name) LIKE '%cocktail%' OR
    -- Generic entries
    (name = 'Scotch Whisky' AND brand = 'Unknown') OR
    LENGTH(name) < 5;
```

## VALIDATION RULES FOR HIGH-QUALITY ENTRIES

### Mandatory Fields:
1. **name**: Length >= 5, not generic, properly formatted
2. **brand**: Not "Unknown", not truncated, proper capitalization
3. **type**: Must be valid spirit type (Bourbon, Scotch, Rum, Tequila, etc.)
4. **data_quality_score**: Must be >= 60 for acceptance

### Quality Indicators:
- Has price (numeric, not text)
- Has ABV (between 20-70%)
- Has meaningful description (>50 chars, not search snippets)
- No duplicate entries
- Proper formatting (spaces, capitalization)
