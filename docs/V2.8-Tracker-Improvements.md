## Current Issues Identified

### 1. Data Quality Issues

#### a) Non-Spirit Entries Still Being Scraped
- **Cocktail Recipes**: "Gin Mule Cocktail Recipe", "Pink Gin Cocktail Recipe", "Gin Sonic Cocktail Recipe"
- **Generic Pages**: "Fry's Food Stores", "Gerbes Super Markets", "Foods Co."
- **Non-Product Entries**: "Australian Grain Fed Beef Gin Gyu", "Trench Firewa Ll Gin B Lack"

#### b) Poor Spirit Name Quality
- **Truncated/Malformed Names**: 
  - "W L Weller C.y.p.b.bourbon" (should be "W.L. Weller C.Y.P.B. Bourbon")
  - "Elijah Craig'ryder Cup'toasted" (apostrophe issues)
  - "Help Us Ditch This 42% Maker's Mark K&l Spirits Journal" (blog title)
  
#### c) Data Extraction Issues
- **Region Field Pollution**: Contains search vector fragments instead of actual regions
  - Example: "41 'chew':56 'cinnamon':34 'corn':23 'craig':2"
- **Missing ABV/Proof**: Many entries have 0 ABV despite being valid spirits
- **Brand Extraction**: Poor brand extraction leading to rejected entries

### 2. Scraper Performance Issues

#### a) Duplicate Detection Working but High Rate
- Many duplicates detected and rejected (good)
- But suggests queries are finding same products repeatedly
- Example: "David E. Wheated Bourbon" found multiple times

#### b) Pre-Storage Validation Rejections
- "Invalid brand name" issues for legitimate spirits
- "Generic single-word brand" causing rejections
- Example: "1792 Bourbon Sweet Wheat Bourbon" rejected due to brand extraction

#### c) Smart Validator Overly Aggressive
- Rejecting valid spirits with 0.00 confidence
- Examples:
  - "Our Bourbon - 1792 Bourbon"
  - "Widow Jane Black Opal 20 Years Old"
  - "Local Whiskey | State College's Premier Whiskey Bar"

### 3. Category Classification Issues

#### a) Wrong Spirit Types
- Rye whiskeys classified as Bourbon (e.g., "Wild Turkey...Kentucky Straight Rye" -> Bourbon)
- Non-spirits classified as spirits

#### b) Query Quality Issues
- Generic queries like "local bourbon delivery near me" returning non-products
- "bourbon gift guide 2025" returning articles instead of products

## Proposed Improvements for V2.8

### Priority 1: Critical Fixes

1. **Enhanced Non-Product Filter**
   - Add explicit filters for:
     - Cocktail recipes (pattern: "cocktail recipe")
     - Store/market names without product info
     - Blog/article titles
     - Food items incorrectly matched
   
2. **Improved Brand Extraction**
   - Fix brand extraction for numbered brands (1792, 1776, etc.)
   - Handle possessive apostrophes correctly
   - Extract brand from distillery names when brand is unclear

3. **Region Field Fix**
   - Clear search vector contamination from region field
   - Implement proper region extraction from descriptions
   - Add validation to prevent non-region data

### Priority 2: Quality Enhancements

1. **Name Normalization Improvements**
   - Fix spacing in abbreviated names (C.Y.P.B., W.L., etc.)
   - Handle special characters and quotes properly
   - Standardize apostrophes and quotation marks

2. **Smart Validator Tuning**
   - Reduce false positives by adjusting confidence thresholds
   - Add whitelist for known edge cases (Widow Jane, numbered brands)
   - Improve handling of distillery-specific products

3. **Query Optimization**
   - Remove or refine generic queries that produce non-products
   - Focus on product-specific search patterns
   - Avoid "guide", "delivery", "near me" type queries

### Priority 3: Performance Optimizations

1. **Duplicate Prevention**
   - Implement query deduplication before API calls
   - Track successful product URLs to avoid re-querying
   - Use more specific initial queries

2. **Better Site Selection**
   - Prioritize sites with structured product data
   - Avoid sites that frequently return non-products
   - Implement site-specific parsing rules

3. **Data Quality Scoring Enhancement**
   - Adjust scoring weights for better accuracy
   - Add specific rules for known patterns
   - Implement category-specific validation
