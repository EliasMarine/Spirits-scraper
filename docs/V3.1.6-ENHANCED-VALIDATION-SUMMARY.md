### 3. Early Rejection in Search Results (`spirit-extractor.ts`)

#### Enhanced Filtering Chain:
1. **URL Validation**: Filter non-product URLs
2. **E-commerce Metadata**: Remove shipping/SKU metadata
3. **V3.1.6 Enhancement**: Early content validation

```typescript
// V3.1.6: Enhanced early rejection for blog/article/forum content
const productResults = cleanResults.filter(item => {
  // Use comprehensive quality validator for early rejection
  if (comprehensiveDataQualityValidator.hasCriticalErrors({ 
    name: item.title, 
    source_url: item.link 
  })) {
    logger.debug(`🚨 Early rejection - Non-product content: "${item.title}"`);
    return false;
  }
  
  // Additional search result specific patterns
  const title = item.title.toLowerCase();
  
  // Reject blog/article titles, forum posts, podcasts, top X lists
  if (title.includes('review') && (title.includes('blog') || title.includes('article'))) return false;
  if (title.includes('forum') || title.includes('discussion')) return false;
  if (title.includes('podcast') || title.includes('episode')) return false;
  if (/top\s+\d+|best\s+of\s+\d{4}|my\s+top\s+\d+/i.test(title)) return false;
  
  return true;
});
```
