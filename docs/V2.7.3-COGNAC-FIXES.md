# V2.7.3 & V2.7.4 Cognac Storage Fixes

## V2.7.3 Issue Summary
- **Problem**: Cognac spirits were being found (152 found) but 0 were being stored
- **Root Cause**: Multiple issues in the cognac scraping and validation pipeline

## V2.7.4 Database Cleanup Issues (June 2025)
- **Problem**: Manual database review revealed numerous invalid entries and duplicates
- **Root Cause**: Scraper allowing non-spirit items and store name duplicates to be stored

## Issues Fixed

### 1. Pre-Storage Validator Spirit Type Check (FIXED)
- The pre-storage validator was penalizing spirits that didn't have type words in their name
- Many cognacs don't include "cognac" in the name (e.g., "Hennessy VS", "Remy Martin VSOP")
- **Fix**: Updated pre-storage-validator.ts to not penalize if spiritData.type is already set

### 2. Brand Extraction Error (FIXED)
- Ultra-efficient scraper was calling `this.extractBrandFromName()` instead of `TextProcessor.extractBrandFromName()`
- This caused brand extraction to fail completely
- **Fix**: Updated all occurrences to use the static method from TextProcessor

### 3. Query Quality Issues (ONGOING)
- Many search results for cognac are not actual products:
  - Gift sets and collectors editions (often rejected by smart validator)
  - Articles about cognac ("France's cognac producers weather climate change")
  - Non-spirit items (notebooks, leather goods with "cognac" color)
  - Events and awards ("World Cognac Awards 2025")

## Remaining Issues

### 1. Smart Validator Too Strict for Gift Sets
- "Collector's Gift Set - Martingale Cognac" rejected with confidence 0.00
- Need to review if legitimate cognac gift sets should be allowed

### 2. Brand Extraction for Complex Names
- "Hennessy XO NBA Collectors Edition Cognac" => Brand: "Hennessy XO NBA Collectors"
- Should be just "Hennessy"
- The VSOP/XO pattern is matching but taking too many words

### 3. Pre-Storage Validation Still Failing
- Even with fixes, cognacs are still failing pre-storage validation
- Need to investigate the quality score calculation

## Testing Results

- Stored: 0 spirits
- All cognacs failed storage

### After Fixes (Partial)
- Brand extraction now working
- Pre-storage validator no longer penalizes missing type in name
