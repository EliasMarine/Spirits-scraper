# V3.1.3 - Critical Data Quality Issues & Fixes

**Date**: June 27, 2025  
**Scope**: Deep audit of 500 recent entries + 7-day analysis  
**Severity**: CRITICAL - Major data quality issues requiring immediate intervention

## Executive Summary

Database audit reveals severe data quality issues:
- **74.8%** of entries missing prices (critical for e-commerce)
- **26%** have quality scores below 50
- **191** entries with invalid brand patterns
- **159** entries with volume suffixes in names
- Significant duplicate issues (up to 4x per product)

## Critical Issues Found

### 1. Invalid Brand Patterns (191 entries)

**Pattern**: Generic/invalid words used as brand names
```
Examples:
- "Unknown" (274 total occurrences!)
- "The" (e.g., "The Macallan" → brand: "The")
- "Year Old" (e.g., "Year Old Single Malt" → brand: "Year Old")
- "Reviews On" (review content as brand)
- "The Essential" (blog title as brand)
- "News" (news articles)
- "Mystery" (mystery boxes)
- "Top Premium" (marketing language)
```

**Root Cause**: Poor brand extraction logic splitting on common patterns

### 2. Volume/Container Suffixes (159 entries)

**Pattern**: Product names ending with volume or container info
```
Examples:
- "Jameson Irish Whiskey Bottle"
- "Glenfiddich 12 Year 750ml"
- "Hennessy VS Cognac 70 cl"
- "Jack Daniel's 1 L"
```

**Impact**: Unprofessional appearance, search/matching issues

### 3. Review/Blog Content (14+ entries)

**Pattern**: Non-product content stored as products
```
Examples:
- "Speyside Single Malt Scotch Reviews Ratings And Facts Best"
- "The Eight Essential Scotch Whisky Bottles For Your Home Bar"
- "These Peaty Scotches Taste Like Campfire In A Glass"
- "Reviews On Glenlivet 12 Glenfiddich 12 And Glenmorangie Original"
```

### 4. Mystery/Subscription Boxes (22 entries)

**Pattern**: Subscription services stored as products
```
Examples:
- "Mystery Whiskey Box Monthly Subscription"
- "Bourbon Subscription Box Premium Selection"
- "Compass Box The Circle No. 2" (subscription service)
```

### 5. Store/Collection Pages (3+ entries)

**Pattern**: Category pages stored as individual products
```
Examples:
- "Buffalo Trace Products Collection"
- "Bourbon Page 3"
- "Styles & Categories Whiskey"
```

### 6. Restaurant/Venue Content

**Pattern**: Restaurant listings as products
```
Examples:
- "Louisville's Premier Steakhouse Bourbon Selection"
- "Bourbon Bar Offering Premium Selection"
```

### 7. Broken Name Extraction

**Pattern**: Incomplete or malformed product names
```
Examples:
- "Year Old Extremely Rare Single Malt Scotch Whisky" (missing number)
- "The Maca Llan Scotch Whisky Hom" (broken spacing and truncation)
- "L L" or "Ll" (spacing issues)
```

### 8. Missing Critical Data

**Statistics**:
- **374/500** (74.8%) missing prices
- **125/500** (25%) missing descriptions
- **130/500** (26%) have quality scores < 50

### 9. Duplicate Entries

**Pattern**: Same product stored multiple times
```
Examples:
- "Highland Park Highland Single Malt Scotch 12 Year Old Whisky" (4 duplicates)
- "Elijah Craig Small Batch Bourbon" (3 duplicates)
- "Buffalo Trace Bourbon" (2 duplicates, different brands)
```

```sql
-- Brands that indicate non-product content

'^(Reviews On|The Essential|These Peaty|Whisky|Rum|Bourbon|Gin|Vodka)$'
```

### Names Requiring Cleanup
```sql
-- Remove suffixes
'\s+(Bottle|70\s*cl|750\s*ml|1\s*L|1L)$'
-- Fix spacing
'\bL\s+L\b' → 'll'
'\bLl\b' → 'll'
```
