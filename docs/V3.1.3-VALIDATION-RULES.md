# V3.1.3 Comprehensive Validation Rules

**Date**: June 27, 2025  
**Purpose**: Define strict rules for high-quality spirit entries  
**Target**: 95%+ data quality across all fields

## Core Validation Rules

### 1. Product Name Rules

#### MUST Requirements
- **Length**: 10-100 characters
- **Format**: Proper capitalization, no ALL CAPS
- **Content**: Must contain actual product name, not descriptions
- **Spirit type**: Must include or imply spirit type

#### MUST NOT Requirements
- No volume/container suffixes (Bottle, 750ml, 1L, etc.)
- No store names or locations
- No review/rating language
- No marketing phrases ("Best", "Top 10", etc.)
- No HTML or special characters (except apostrophes)
- No truncation indicators (..., etc.)

#### Edge Cases
- Vintage years allowed (e.g., "2019 Limited Release")
- Roman numerals allowed (e.g., "Batch XIII")
- Foreign language names allowed if legitimate product
- Abbreviations allowed if standard (e.g., "VS", "XO", "BiB")

### 2. Brand Validation Rules

#### MUST Requirements
- **Length**: Minimum 3 characters
- **Format**: Proper capitalization
- **Uniqueness**: Not a generic word
- **Validity**: Must be actual producer/brand

#### MUST NOT Requirements
- No generic spirit types as brand
- No descriptive words (The, Our, New, Best)
- No extraction artifacts (Year Old, Unknown)
- No partial words or truncations

#### Valid Brand Examples
```
✓ Buffalo Trace
✓ Maker's Mark
✓ The Macallan (full brand, not just "The")
✓ E.H. Taylor (abbreviations OK)
✓ Wild Turkey 101 (numbers OK if part of brand)
```

#### Invalid Brand Examples
```
✗ Unknown
✗ The
✗ Bourbon
✗ Year Old
✗ Premium
✗ Reviews On
```

### 3. Price Validation Rules

#### MUST Requirements
- **Required**: Yes (for reputable sources)
- **Format**: Numeric or string with currency
- **Range**: $5.00 - $10,000.00
- **Currency**: USD (convert if needed)

#### Extraction Priority
1. Structured data markup
2. Price near "Add to Cart"
3. Price near volume (750ml)
4. MSRP or retail price
5. Range (use lower bound)

#### Price Red Flags
- Under $5: Likely miniature or error
- Over $10,000: Requires verification
- Round numbers ending in 00: Verify accuracy

### 4. Category Rules

#### Valid Categories (Strict List)
- Bourbon
- Rye Whiskey
- Tennessee Whiskey
- Scotch
- Irish Whiskey
- Japanese Whisky
- Canadian Whisky
- American Single Malt
- Gin
- Vodka
- Rum
- Tequila
- Mezcal
- Cognac
- Brandy
- Liqueur

#### NEVER Use "Other"
- Must match to specific category
- If uncertain, use broader category (e.g., "Whiskey")
- Reject if no clear category

### 5. Description Rules

#### MUST Requirements
- **Length**: 50-500 characters
- **Content**: Product-focused
- **Language**: Professional, descriptive
- **Format**: Complete sentences

#### MUST NOT Requirements
- No reviews or ratings
- No user comments
- No navigation text
- No store policies
- No HTML tags
- No truncation

#### Good Description Example
```
"A classic Kentucky straight bourbon whiskey aged for 7 years in new charred oak barrels. Features notes of vanilla, caramel, and oak with a smooth finish."
```

### 6. Technical Data Rules

#### ABV/Proof
- **Range**: 20-80% ABV (40-160 proof)
- **Format**: Numeric only
- **Validation**: Proof = ABV * 2

#### Age Statement
- **Format**: Number + "Years" or "Year"
- **Range**: 1-100 years
- **Validation**: No marketing age (established dates)

#### Volume
- **Standard**: 750ml, 1L, 1.75L, 375ml
- **Format**: Separate field, not in name
- **Required**: Yes

### 7. Data Quality Scoring

#### Quality Score Calculation
```
Base Score: 100
- Missing price: -20
- Missing/bad brand: -15  
- Missing description: -10
- Generic category: -10
- No technical data: -5 per field
- Failed validation: -15 per failure
```

#### Minimum Thresholds
- **Standard spirits**: 50
- **Premium spirits**: 60
- **With price**: Can go as low as 35
- **Emergency reject**: < 25

### 8. Duplicate Prevention Rules

#### Exact Match
- Same name (case insensitive)
- Same brand
- Same volume

#### Fuzzy Match (85% threshold)
- Similar name
- Same brand
- Within $5 price range
- Same category

#### Resolution
- Keep entry with:
  1. Price data
  2. Higher quality score
  3. More complete data
  4. Earlier creation date

### 9. Source-Specific Rules

#### Premium Sources (Must Have Price)
- totalwine.com
- thewhiskyexchange.com
- klwines.com
- wine-searcher.com
- masterofmalt.com

#### Review Sites (Reject)
- blog domains
- review platforms
- forum sites
- social media

### 10. Special Cases

#### Cognac/Brandy
- May not have "Cognac" in name
- Grade indicators validate (VS, VSOP, XO)
- Age statements in years
- Region validates (Grande Champagne, etc.)

#### Japanese Whisky
- Romanized names OK
- Distillery names validate
- May use "Whisky" spelling
- NAS (No Age Statement) common

#### Limited Editions
- Batch numbers validate
- Release years validate
- Higher prices expected
- Unique names expected

## Validation Pipeline

```
1. Pre-extraction validation
   - Source quality check
   - URL pattern validation
   
2. Extraction validation
   - Each field validated immediately
   - Retry for missing critical fields
   
3. Post-extraction cleanup
   - Name cleaning
   - Brand normalization
   - Description sanitization
   
4. Pre-storage validation
   - All rules applied
   - Quality score calculated
   - Duplicate check
   
5. Storage decision
   - Accept if passes all gates
   - Log rejection reason if failed
```
