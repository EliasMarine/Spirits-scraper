## V3.0 Validation Rules Implemented

### 1. Hard Rejection Patterns
These patterns now trigger immediate rejection:
- Names starting with: "We", "I've", "Top", "Best", "Discover"
- Names containing: "Guide", "Collection", "Reviews", "Tasting Notes"
- Brand names: "Unknown", "We're", "Top Premium", "[Age] Year Old"
- Product pages: "Product Detail", "Product Description"

### 2. Name Cleaning
- Auto-remove suffixes: "Bottle", "70 cl", "750ml"
- Length enforcement: 15-70 characters
- Special character removal: "»", "|", "•"

### 3. Brand Validation
- Minimum 2 characters
- Cannot be generic terms
- Must start with letter/number
- Age patterns not allowed as brands
