## V3.0 Validation Rules

### 1. Name Validation
- **Length**: 15-70 characters (strict)
- **Forbidden Patterns**:
  - Starting with: "We", "I've", "Top", "Best", "Discover", "New"
  - Containing: "Guide", "Collection", "Reviews", "Tasting Notes"
  - Special chars: "»", "|", "•"
  - Ending with: "Bottle", "70 cl", "750ml"

### 2. Brand Validation
- **Required**: Cannot be "Unknown"
- **Forbidden Brands**: 
  - Single words: "We're", "Top", "Best", "White", "Navy"
  - Age patterns: "X Year Old"
  - Generic: "Unknown", "Various", "Multiple"
- **Minimum**: 2 characters, must start with letter/number

### 3. Content Type Detection
Reject if matches:
- Blog post patterns: /^(We|I've|You|The) .* (Tried|Tasted|Living)/
- List articles: /^\d+ (Best|Top|Absolute)/
- Category pages: /(Highland|Islay|Navy|White) (Single Malt|Rum)$/
- Store pages: /Discover|Collection|Arrivals|Samples/

### 4. Source URL Validation
Enhanced checks for:
- Blog URLs containing: /blog/, /article/, /guide/
- Category URLs: /collections/, /category/
- Review URLs: /reviews/, /tasting-notes/
